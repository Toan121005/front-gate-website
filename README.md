# Front Gate – Thai Food Heritage Website

A bilingual (English / Thai) website that documents five traditional Thai dishes
with Front Gate Restaurant near Asia-Pacific International University (AIU).
Built for IT363 Front-End Web Development (Community Project, CP1: Skeleton and repository).

## Mission

Help AIU students and visitors discover the family stories and food heritage
behind Front Gate's dishes, in both English and Thai, with content approved by
the people who hold the knowledge.

## Community partner

- Front Gate Restaurant, near AIU, Muak Lek, Saraburi, Thailand
- Contact: Mali Chaiyawan (manager)

## Scope

Five dishes: Pad Thai, Pad Kra Pao, Tom Yum Goong, Khao Pad, Som Tum.

## Tech

- HTML5 (semantic structure)
- Tailwind CSS (mobile-first, tested at 360 px and desktop)
- JavaScript (language switch, search and filter)
